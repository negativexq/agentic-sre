## Offline orchestration baseline

The current local benchmark uses `FakeModelProvider` with scripted decisions.
It validates runtime behavior, tool dispatch, evidence authority, hypothesis
validation, audit accounting, and deterministic graders. It is intentionally
not a measurement of live model quality.

```text
Completion rate:                  100%
Composite RCA:                    1.00
Valid evidence reference rate:    100%
Model calls / incident:            2.00 scripted turns
Tool calls / incident:             1.00
Total live API calls:              0
```

Run it with:

```shell
make benchmark-offline
```

## Live baseline policy

Live provider smoke and live incident benchmark commands are explicit opt-in
operations. They are not part of `make check`, CI, or the offline benchmark.
The live benchmark uses one pass per scenario, disables retries for a
reproducible worst-case of 30 outbound attempts, and reports model calls,
input/output tokens, latency, terminal outcomes, and total live API calls in a
machine-readable artifact. The shared global budget is operator-configured and
is never reset by release automation.

Because this baseline intentionally runs one pass per scenario, variance
estimates are deferred.

The live report is written to
`docs/benchmarks/v0.2.0-single-agent-live.json` only after a complete ten-case
run. Offline results must never be presented as live model quality.

## Frozen live GPT-5.6 Luna baseline

The live benchmark was executed once, in frozen dataset order, against ten
fresh real fault-to-telemetry-to-Alertmanager-to-Incident trials. The model
configuration was GPT-5.6 Luna with reasoning effort `none`, no router,
fallback, or voting, three model calls per incident, eight actual tool
executions per incident, and zero provider retries.

```text
Duplicate requests suppressed:     0
Input tokens:                      99,505 total
Output tokens:                      4,741 total

Terminal outcomes:                 9 HYPOTHESIS_SUBMITTED, 1 AGENT_STOPPED

Live API attempts:                 30

```

The full per-scenario record, hashes, accounting invariant, safety metrics,
terminal distribution, and failure taxonomy are in
`v0.2.0-single-agent-live.json`.

The v0.2.0 live benchmark executes each frozen scenario exactly once.
This single-pass methodology intentionally bounds paid API usage and
establishes a reproducible baseline; it does not estimate run-to-run model
variance.
