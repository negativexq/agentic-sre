# v1.1.1 — Checkpoint-Safe Bounded Investigation Agent

v1.1.1 is a patch release for the bounded LangGraph investigator introduced in
v1.1.0.

## Fixed

- LangGraph checkpoints now contain portable logical investigation state only.
- `ObservationSource`, policies, LLM clients, tools, case builders, and other
  runtime services remain bound to graph nodes and are never checkpointed.
- The default serializer disables arbitrary pickle fallback, so accidental
  runtime-object leakage fails closed.
- Resumed no-progress detection now normalizes tuple/list representation changes
  introduced by checkpoint serialization.
- Fresh runtime instances can resume a checkpoint while preserving observations,
  findings, budgets, fingerprints, and attempt history.

This fixes the checkpoint boundary defect that prevented the v1.1.0 canonical
real-model TEST evaluation from reaching its first model or tool call.

## Trust boundary

The model still selects only an allowlisted read-only observation. Deterministic
normalization, hypothesis rebuilding, verification, resolution, confidence, and
root-cause selection remain authoritative. No cluster writes or autonomous
remediation were added.

## Validation

The release includes checkpoint serialization, locked-client, unpickleable
source, fresh-runtime resume, Case rebuild/cache, and resumed no-progress
regressions, alongside the existing investigation suite and real Kind gate.
