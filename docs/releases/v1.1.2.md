# v1.1.2 — Strict OpenAI Investigation Contract

v1.1.2 is a patch release for the bounded investigation agent. It does not
change deterministic RCA, ranking, verification, resolution, or confidence
semantics.

## Fixed

- The OpenAI Responses API action output now uses a dedicated strict wire DTO.
- All action fields are required, with nullable fields represented explicitly
  as `null`.
- The nested target object is also strict and rejects unknown properties.
- Provider request diagnostics preserve sanitized exception, status, code,
  parameter, request ID, and message details instead of collapsing failures to
  an opaque `BadRequestError`.

The provider-facing DTO remains separate from the provider-neutral RCA domain
models. The model can still select only an allowed read-only observation; the
deterministic engine remains authoritative for evidence interpretation,
verification, resolution, confidence, and root-cause selection.

## Validation

The release was validated with recursive strict-schema tests, provider error
diagnostic tests, the existing investigation suite, the full test suite, image
builds, offline demo, and the real Kind release gate. A live one-request smoke
confirmed that `gpt-5.6-luna` returns a valid structured investigation action.
