## Bounded-agent evaluation status

The real-model Phase B run was **not a valid agent evaluation** and is reported
as blocked rather than converted into a partial result.

Credentials were available and the fixed released configuration was selected
before execution:

- Provider: OpenAI Responses API
- Model: `gpt-5.6-luna`
- `max_turns=6`
- `max_model_calls=6`
- `max_tool_calls=8`
- `max_tool_calls_per_gap=2`
- `max_invalid_actions=2`
- `max_no_progress_rounds=2`
- `max_wall_time_seconds=120`

The run reached the first eligible incident, `Scenario-14`, but failed before
the first model or tool call. The default released `InMemorySaver` attempted to
checkpoint a state containing the live `SnapshotSource`. Serialization failed
with:

```text
TypeError: Type is not msgpack serializable: SnapshotSource
TypeError: cannot pickle '_thread.lock' object
```

This is a released production checkpoint/state-boundary defect, not a provider
result. Consequently there are no valid v1.1.0 bounded-agent measurements for
resolution gain, recovery, harm, tool yield, stop reasons, or model-output
reliability. The run was not rerun with a different checkpointer, model, or
configuration, and no production code was changed in response to TEST output.

The attempted run had zero model calls and zero tool calls before it was
invalidated. Partial files are retained only as an audit trail and must not be
aggregated as agent predictions.

## Safety invariants

The bounded-agent invariants were not evaluated end-to-end on TEST because the
checkpoint failure occurred before action selection. No invalid action reached
tool execution in the attempted run, but this is not evidence of full-run
policy safety. A valid post-fix evaluation must measure invalid actions,
out-of-scope attempts, `NO_DATA`, `UNKNOWN`, duplicate actions, and model
authority violations separately.

## Decision

The deterministic v1.1.0 TEST result is valid and sealed. The bounded
investigation agent's incremental value is **not established** by this
evaluation because the released checkpoint boundary prevented a valid run.
The next engineering work should first make investigation state portable or
exclude runtime-only objects such as `SnapshotSource` from checkpointed state,
then repeat one canonical post-fix evaluation. The v1.1.0 tag remains
immutable.
