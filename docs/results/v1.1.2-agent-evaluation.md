# v1.1.2 bounded-agent observational evaluation

This post-release evaluation used the immutable `v1.1.2` tag at commit
`6e1bdbf4ec0f40e24e73e55294bbc5ed44db1d88`. Production RCA behavior was not
changed during the run.

## Provider and run identity

- Provider: OpenAI Responses API
- Model: `gpt-5.6-luna`
- SDK: `2.54.0`
- Eligible scenarios: `Scenario-14`, `Scenario-19`, `Scenario-25`,
  `Scenario-35`, `Scenario-80`, `Scenario-81`, `Scenario-83`
- Budgets: 6 turns, 6 model calls, 8 tool calls, 2 calls per gap, 2 invalid
  actions, 2 no-progress rounds, 120 seconds
- Process provider budget: 64 calls
- Ground truth was not available to the prediction process.

The eligibility set was read from the released deterministic prediction state:
resolution was `AMBIGUOUS` or `INSUFFICIENT_EVIDENCE`, with a non-empty
`RESOLVABLE` gap and candidate capability.

## Investigation result

All seven eligible investigations completed with accepted provider responses
and real read-only tool calls. Every investigation ended with
`NO_PROGRESS`; none became `RESOLVED`.

| Metric | Result |
| --- | ---: |
| Provider attempts | 19 |
| Accepted/completed responses | 19 |
| Provider request failures | 0 |
| Parsed actions | 19 |
| Tool calls | 19 |
| Useful evidence-producing calls | 3 |
| Duplicate/already-known evidence calls | 15 |
| Unique evidence refs added | 18 |
| NO_DATA observations | 1 |
| UNKNOWN observations | 10 |
| Invalid actions | 0 |
| Stop reason | 7 × `NO_PROGRESS` |

The resolution transition was:

```text
AMBIGUOUS → AMBIGUOUS: 7
AMBIGUOUS → RESOLVED:   0
```

Correctness transitions for eligible cases were:

```text
correct → correct: 6
wrong   → wrong:   1
wrong   → correct: 0
correct → wrong:   0
```

Therefore recovery was `0`, harm was `0`, and the investigation produced no
measured incremental benchmark value in this run. It also did not damage an
already-correct diagnosis.

## Full-set observational effect

Combining the unchanged deterministic diagnoses for the 18 non-eligible cases
with the seven bounded-agent results produced the same official TEST metrics:


The agent was operational and provider-compatible, but this single canonical
run did not resolve any ambiguity. It therefore demonstrates safe bounded
evidence acquisition, not a measurable accuracy improvement.
